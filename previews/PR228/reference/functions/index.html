Functions and methods

The examples show these abbreviations in docstrings, with the source they render from.

DocStringExtensions.SIGNATURES — Constant

An Abbreviation that prints the signatures of the documented method, with argument names and keywords but no types. See printmethod for the simplifications it applies.

Examples

julia> """
       $(SIGNATURES)
       Compute the area of a rectangle.
       """
       area(width, height = width) = width * height;

julia> @doc area
  area(width)
  area(width, height)

  Compute the area of a rectangle.
Showing Default Values

Default values of positional and keyword arguments are omitted. To show them, use $(DocStringExtensions.MethodSignatures(defaults = true)). The methods that Julia generates for positional defaults are then printed as a single signature.

source
DocStringExtensions.TYPEDSIGNATURES — Constant

An Abbreviation that prints the signatures of the documented method like SIGNATURES, with argument types and the inferred return type. See printmethod for the simplifications it applies.

Examples

julia> """
       $(TYPEDSIGNATURES)
       Compute the area of a rectangle.
       """
       area(width::Int, height::Int) = width * height;

julia> @doc area
  area(width::Int64, height::Int64) -> Int64

  Compute the area of a rectangle.
Disabling the Return Type

The return type is often inferred as Any. To leave it out, use $(DocStringExtensions.TypedMethodSignatures(false)).

Showing Default Values

Default values of positional and keyword arguments are omitted. To show them, pass defaults = true: $(DocStringExtensions.TypedMethodSignatures(true; defaults = true)). The methods that Julia generates for positional defaults are then printed as a single signature.

DocStringExtensions.FUNCTIONNAME — Constant

An Abbreviation that prints the name of the documented function. Use it in a signature written by hand, for example on a function with no methods yet.

The name is printed as plain text. Indent it or wrap it in backticks to format it as code.

Examples

julia> """
       `$(FUNCTIONNAME)(d, θ)` calculates the log density of `d` at `θ`.
       """
       function logdensity end;

julia> @doc logdensity
  logdensity(d, θ) calculates the log density of d at θ.
source
DocStringExtensions.METHODLIST — Constant

An Abbreviation that lists the methods of the documented function or type that are defined in the current module. Each method shows its signature and a link to the line that defines it.

Examples

Methods defined in the REPL have no file to link to, so the list below shows only their signatures.

julia> """
       Scale `x` by a factor.
       $(METHODLIST)
       """
       function scale end;

julia> scale(x) = 2x;

julia> scale(x, factor) = factor * x;

julia> @doc scale
  Scale x by a factor.

  scale(x, factor)
  scale(x)
source
DocStringExtensions.TYPEDMETHODLIST — Constant

An Abbreviation that lists methods like METHODLIST, with argument types and the inferred return type in each signature.

Examples

julia> """
       Scale `x` by a factor.
       $(TYPEDMETHODLIST)
       """
       function scale end;

julia> scale(x::Int) = 2x;

julia> scale(x::Float64, factor::Float64) = factor * x;

julia> @doc scale
  Scale x by a factor.

  scale(x::Float64, factor::Float64) -> Float64
  scale(x::Int64) -> Int64
Disabling the Return Type

The return type is often inferred as Any. To leave it out, use $(DocStringExtensions.TypedMethodList(false)).
