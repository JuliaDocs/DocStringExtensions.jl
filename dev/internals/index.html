DocStringExtensions.alltypesigs — Method
alltypesigs(sig)

The Tuple types in sig, the signature a docstring is paired with. A docstring that documents several methods at once, such as those that positional default values define, is paired with the union of their signatures. Returns an empty vector for Union{}.

julia> DocStringExtensions.alltypesigs(Tuple{String,Number,Int})
1-element Vector{Any}:
 Tuple{String, Number, Int64}

julia> DocStringExtensions.alltypesigs(Tuple{T} where T <: Integer)
1-element Vector{Any}:
 Tuple{T} where T<:Integer

julia> s = Union{
         Tuple{Int64},
         Tuple{U},
         Tuple{T},
         Tuple{Int64,T},
         Tuple{Int64,T,U}
       } where U where T;

julia> DocStringExtensions.alltypesigs(s)
5-element Vector{Any}:
 Tuple{Int64}
 Tuple{U} where U
 Tuple{T} where T
 Tuple{Int64, T} where T
 Tuple{Int64, T, U} where {T, U}

append_defaults(
    args,
    kws,
    kwnames,
    method,
    definition;
    brackets
)

Append =default to each formatted argument in args and keyword in kws that has a default value in definition. kwnames names the keyword formatted in each entry of kws. DocStringExtensions.constructor_methods — Method
constructor_methods(func, typesig)

The methods of Type{T}, for T any instance of the parametric type func, whose arguments match typesig. These are the constructors written as T{P}(...). Julia stores D{T}(g) for struct D{T,MM} under Type{D{T}}, with MM free inside the invariant Type, so each leading run of func's parameters is searched.

DocStringExtensions.groupby — Method
groupby(f, K, V, data)

Group data using function f where key type is specified by K and group type by V.

The function f takes a single argument, an element of data, and should return a 2-tuple of (computed_key, element). See the example below for details.

Examples

    mod(num, 3), num
end

DocStringExtensions.interpolation — Method
interpolation(object::T, captured::Expr) -> new_object

Interface method for hooking into interpolation within docstrings to change the behaviour of the interpolation. object is the interpolated object within a docstring and captured is the raw expression that is documented by the docstring in which the interpolated object has been included.

To define custom behaviour for your own object types implement a method of interpolation(::T, captured) for type T and return a new_object to be interpolated into the final docstring. Note that you must own the definition of type T. new_object does not need to be of type T.

source
DocStringExtensions.keyword_body — Method
keyword_body(method)

The method holding the body of method, a method with keyword arguments, or nothing when it cannot be found. Julia lowers f(x; a::Int = 1) to a method of f that fills in the keyword defaults and ends by calling a hidden body method, #f#1(a::Int, ::typeof(f), x).

DocStringExtensions.printmethod — Method
printmethod(
    buffer::IOBuffer,
    binding::Base.Docs.Binding,
    func,
    method::Method,
    typesig;
    returns,
    definition,
    brackets
) -> IOBuffer

Print a method signature to buffer with the argument types from typesig and the declared types of the keyword arguments, followed by the return annotation that returns selects (see return_annotation). Type parameters keep their names and are declared in a where clause after the arguments. Default values are left out unless definition gives them.

definition is as for the untyped printmethod.

Examples

f(x::Int; a = 1, b...) = x
sig = printmethod(Docs.Binding(Main, :f), f, first(methods(f)))
source
DocStringExtensions.printmethod — Method
printmethod(
    buffer,
    binding,
    func,
    method;
    definition,
    returns,
    brackets
)

Print a simplified representation of a method signature to buffer. Some of these simplifications include:

  • no TypeVars, except those of a callable on Type{T}, such as (::Type{T})(x) where T<:Number;
  • no types, except ::T for an unnamed argument of type T;
  • no default values, unless definition gives them;
  • _ printed for untyped unnamed arguments, and for destructured arguments unless definition gives them;
  • a macro printed as its caller writes it, @m a b, without __source__ and __module__ or an inferred return type.

definition is the DefinitionArguments of the documented method definition, or nothing. returns selects the return_annotation after the signature.

Examples

f(x; a = 1, b...) = x
sig = printmethod(Docs.Binding(Main, :f), f, first(methods(f)))

DocStringExtensions.return_annotation — Method
return_annotation(returns, func, method, typesig)

The -> T that follows a signature, with the return_arrow. returns is true for the type that method is inferred to return for typesig, false for none, or the text to print as T. An inferred type that still shows a name Julia generated for a type variable is left out.

DocStringExtensions.signature_width — Method
signature_width()

The longest signature, in characters, that prints on one line: the value of DOCSTRINGEXTENSIONS_SIGNATURE_WIDTH, or 60 when it is unset or empty. A longer signature prints one argument per line. A value that is not a positive integer warns and gives 60.

source
DocStringExtensions.signatures_equal — Method
signatures_equal(group, typesig)

Whether the methods of group together have the signature typesig. Subtyping cannot prove that for a vararg tuple split across methods, such as Tuple{Vararg{T}} where T and the two methods of f(x::T = 1, xs::T...) where {T}. So the types are compared at each number of arguments, up to one past the most parameters any tuple declares. Larger counts only meet varargs and compare the same.

source

The constructors of the type func that its struct definition creates, from the module modname. DocStringExtensions.Abbreviation — Type

Abbreviation objects are used to automatically generate context-dependent markdown content within documentation strings. Objects of this type interpolated into docstrings will be expanded automatically before parsing the text to markdown.

DocStringExtensions.DefinitionArguments — Type

The positional and keyword arguments of a documented method definition, rendered as source text.

positional has a (name, default) entry for each positional argument, in order. name is the argument's name, the destructuring of a destructured argument such as "(a, b)", or "_" for an unnamed argument. default is nothing when the argument has no default. keywords maps the name of each keyword argument with a default to that default.

DocStringExtensions.StructDefinition — Type

Where a documented struct definition ends, which bounds the constructors that its signatures list.

  • file: The file the definition is written in.

  • last_line: The last line of the definition's body.

  • wrapped: Whether a macro wraps the definition, and so may define constructors outside its body.

DocStringExtensions.Template — Type

Internal abbreviation type used to wrap templated docstrings.

Location is a Symbol, either :before or :after. dict stores a reference to a module's templates. expr is the documented expression, which is passed to interpolation for each part of the template.

DocStringExtensions.TemplateOverride — Type

The type for NOTEMPLATE abbreviations.

TemplateOverride(category) applies the module's @template for category to the docstring it appears in, in place of the template for the documented object's own category. category is one of the categories @template accepts, and the module must define a template for it before the docstring.
